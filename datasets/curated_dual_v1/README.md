# PepSeek dual-supervision data release

Status: **preparation in progress**. `catalog-source-v1.tar.gz` contains source-
curated candidate tables and sequence/chemical-identity registries; it is not the
sealed train/valid/test package. Candidate counts are 8,777 quantitative
observations and 76,442 structural observations. These are observation counts,
not independent molecular-pair counts.

The completed release will add the actual component split, clean disposition
ledger, model manifest, structural labels, checksums and acceptance seal here.
See [the curation specification](../../docs/DATA_CURATION.md).
